Version 2.0.1

Software updates

  • New Settings window (⌘,) with control over automatic updates: whether to check at all, how often, and whether to download in the background before asking.
  • Previously the only say you had was Sparkle's one-time prompt on first launch, which never appears again — so whatever was answered then was permanent.
  • The window also reports the running version and when it last managed to check.

Updates are only installed if they carry a valid signature from this application's own key.
