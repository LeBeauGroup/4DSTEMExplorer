Version 2.3.1

Windows

  • The main window can now be resized vertically. It used to be wedged at the height of its sidebar, which on a laptop was taller than the screen, so it could only be dragged wider.
  • The sidebar scrolls. In a short window the detector controls below the pattern are reached by scrolling instead of being cut off.
  • The Calibration window can be dragged larger in both directions.
  • The title bar shows the name of the open file. Right-click or ⌘-click it for the full path.

Display

  • The diffraction pattern has a scale bar, in mrad, whenever the file carries a diffraction calibration.
  • View → Show/Hide Scalebars (⌘B) turns the scale bars on the pattern and the scan image on and off.

The RAW scan dimensions panel

  • The menu of scan orders is gone. A named order chosen against the wrong data is not obviously wrong afterwards — it simply mirrors the scan. A scan is now read in raster order unless the acquisition's own metadata says otherwise or you load a positions file with Load Scan Path…; Use Raster Order clears either.
